# Music Streaming Analytics 🎵

Stream, explore, and analyze music with a clean, interactive dashboard. Browse songs, view artist & album details, and get analytics on your music collection — all in one place.

## Tech Stack
- **Python** – Data processing and scripting  
- **PostgreSQL** – Database to store users, songs, playlists, and listening history  
- **Pandas** – Data cleaning and manipulation  
- **Streamlit** – Interactive dashboard framework  
- **Plotly & Seaborn** – Visualizations for analytics  
- **Faker** – Synthetic dataset generation

---

## Features
- Interactive browsing of songs, artists, albums, and playlists  
- Filter songs by genre, artist, or release year  
- View top songs, popular artists, and playlist statistics  
- Real-time updates from PostgreSQL database  
- Visualizations: bar charts, line plots, heatmaps, and word clouds
